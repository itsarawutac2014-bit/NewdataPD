# Google Sheets Live Dashboard

แดชบอร์ดสรุปข้อมูลดึงจาก Google Sheet แบบอัตโนมัติ เขียนด้วย HTML, Tailwind CSS และ Chart.js

## 🚀 ฟีเจอร์เด่น
- ดึงข้อมูลจาก Google Sheet แบบเรียลไทม์ผ่าน CSV Export
- สรุปตัวเลข KPI Cards (ยอดรวม, ค่าเฉลี่ย, จำนวนรายการ)
- กราฟ Chart.js แสดงยอดขายและสัดส่วนสถานะ
- ค้นหาข้อมูลในตารางแบบสด (Live Filter)
- รองรับการเปิดบนมือถือและคอมพิวเตอร์ (Responsive Design)

## 📌 วิธีใช้งาน
1. เผยแพร่ Google Sheet:
   - ไปที่ `ไฟล์ (File)` > `แชร์ (Share)` > `เผยแพร่ไปยังเว็บ (Publish to web)`
   - เลือกแผ่นงานและเปลี่ยนรูปแบบเป็น `ค่าที่คั่นด้วยเครื่องหมายจุลภาค (.csv)`
   - คัดลอกลิงก์ CSV
2. เปิดหน้าเว็บ Dashboard แล้ววางลิงก์ในช่องกรอกด้านบน แล้วกด **โหลดข้อมูล**
